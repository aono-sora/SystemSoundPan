# SystemSoundPan

macOSのシステム音(ビープ・アラート音)を、最前面ウィンドウの画面上の位置に応じて左右にパンするメニューバー常駐アプリです。
昔のMacintoshのように、ウィンドウが画面の左にあれば左から、右にあれば右から音が聞こえます。
ブラウザの動画など、他のアプリの音には影響しません。(アプリ自身が鳴らす音を対象にしたい場合は、後述の「パン対象のアプリ」で追加できます)

## 作者からの一言

Classic Mac OS(System 7〜Mac OS 9)では、ステレオ対応機でシステムアラート音が画面上のイベント位置に応じて左右にパンニングされる挙動があった。初めてMacintoshに触れた時、この仕組みに感動した覚えがある。ところが現行のmacOSでは、少なくとも私の環境ではこの仕組みを確認できなくなっている。ディスプレイのワイド化や複数ディスプレイ環境が当たり前になった現代だからこそ、この仕組みはあらためて価値を見出せるのではないだろうか。

という純粋な動機から、Claude Codeを使って再現アプリを作ってみました。動作確認など不十分ですが、誰かに刺さってくれれば幸いだと思い公開いたします。

## 本アプリがすること

- システム音を鳴らすプロセス(`systemsoundserverd`)の音だけを取得し、元の音をミュートして、左右バランスを付けて再生し直します
- そのため、macOSの「オーディオ録音」の許可が必要です
- 取得した音声を保存したり、ネットワークに送ったりはしません(通信処理は含まれていません)
- ウィンドウの位置は、最前面アプリのウィンドウの座標だけを読みます。画面の内容やウィンドウのタイトルは読みません
- 通知音(iMessageの着信音など)は、鳴らしたアプリのウィンドウ位置を基準にするため、macOS標準のコマンド `/usr/bin/log stream` を子プロセスとして起動し、「通知音を再生した」「システム音の再生が要求された」というログ行(要求したアプリのバンドルIDやプロセス番号)だけを読みます。それ以外のログの内容は使いません。ログの読み取りに追加の許可は不要です

## 動作条件

- **macOS 14.2 以降**
- **Apple Silicon (M1以降) のみ。** Intel Mac には対応していません

## 動かすための手続き

1. `SystemSoundPan.app` を `/Applications` フォルダにコピーします
2. appをダブルクリックして起動します。「開けません」「開発元を確認できません」と出て止まるのは正常です。いったんそのダイアログを閉じます
3. 「システム設定 → プライバシーとセキュリティ」を開き、下の方に出ている「"SystemSoundPan"は開くのをブロックされました」の横の「このまま開く」を押します。パスワード(またはTouch ID)で認証します

   ターミナルを使える場合は、次の1行でも同じです。
   ```
   xattr -cr /Applications/SystemSoundPan.app
   ```
4. 起動すると、メニューバーにアイコン(スピーカーと左右の矢印)が出ます(Dockには出ません)
5. 「オーディオを録音しようとしています」という許可ダイアログが出たら、許可します
6. **初回の起動時だけ、動き出すまでに十数秒かかることがあります**(許可の確認のため)。許可後は、起動してすぐ動きます。動き出す前のシステム音は、通常どおり(パンなしで)鳴ります
7. ターミナルで `osascript -e 'beep 2'` を実行し、ウィンドウを画面の左右に動かして音の左右が変わるか確認します

## 自動起動

「システム設定 → 一般 → ログイン項目と拡張機能」で「+」を押し、`/Applications/SystemSoundPan.app` を追加します。
外付けドライブ上のappは、未接続だと起動に失敗するので、`/Applications` に置いてください。

## 使い方

- メニューバーのアイコンから、オン/オフの切り替え、「パンの倍率」の調整、「システム音の初期位置」の調整、「ブラウザの音もパンする」の切り替え、「パン対象のアプリ」の追加・削除、終了ができます(オフにするとアイコンのスピーカーに斜線が入り、システム音は元の鳴り方に戻ります)
- 基準にするのは、ウィンドウの中心のX座標です。複数ディスプレイの場合は、全ディスプレイを並べた全体の幅が基準です
- ビープ音などは、最前面アプリのウィンドウが基準です
- 通知音は、通知を出したアプリのウィンドウが基準です(iMessageの着信音で確認済み)。そのウィンドウが他のデスクトップ(Space)にある場合も、その位置が基準です。アプリのウィンドウが見つからないときは、最前面アプリのウィンドウが基準です
- 通知を出したアプリのウィンドウが複数ある場合は、最前面にあるウィンドウを使います
- **アプリが自分で鳴らす音(Teams、Zoom、Slack、Discordなど)は、初期状態では対象外です。** これらのアプリは、システムの通知音の仕組みを使わず、アプリ自身が音を鳴らすためです。メニューの「パン対象のアプリ」で、アプリを追加すると、そのアプリの音を、アプリのウィンドウ位置に合わせて左右に振れます(下記)
- ブラウザ上のWebアプリ(Web版のOutlookなど)が自分で鳴らす通知音は、システム音ではなくブラウザの音なので、初期状態では対象外です(ブラウザの動画などの音を通常どおり出すため)。メニューの「ブラウザの音もパンする」をオンにすると、対象になります。ただし、ブラウザの音は動画も含めて全部が対象になり、動画の音も左右に振れます(映像と音が少しずれる可能性もあります)。動画を見るときはオフに戻すことを推奨します。対応ブラウザは、Chrome、Edge、Brave、Firefox、Safariです。この場合の基準は、ブラウザのウィンドウ位置です。特定のサイトの音だけを振りたい場合もあるので、Chrome拡張機能「Desktop Audio Panner」(許可リスト式)を開発中です。

## パン対象のアプリを追加する

アプリが自分で鳴らす音(Teams、Zoomなど)を、パンの対象にできます。

1. メニューバーのアイコン→「パン対象のアプリ(アプリ自身が鳴らす音)」→「アプリを追加…」を選びます
2. `/Applications` の中から、対象にしたいアプリを選びます
3. 追加したアプリは、一覧に出ます。名前を選ぶと、オン(チェックあり)とオフを切り替えられます。「アプリを削除」で、一覧から外せます

**ご注意ください。**

- **すべてのアプリの音を拾えるとは限りません。** アプリの作り方(音を出すプロセスの構成や、バンドルIDの付け方)によっては、追加しても、パンされない場合があります。動作確認は、作者の環境の限られたアプリだけです
- 追加したアプリの音は、**通知音だけでなく、すべてが対象です。** 通話の相手の声や、共有した動画の音も、左右に振れます。通知音だけを分けることは、できません
- 基準になるのは、そのアプリのウィンドウの位置です。そのウィンドウが他のデスクトップ(Space)にある場合も、その位置が基準です
- 追加したアプリにウィンドウが複数あるときは、次の順で基準を選びます。フォーカスや重なり順は見ません
  1. そのアプリのいちばん大きいウィンドウと比べて、面積が4分の1に満たないものは、小窓とみなして除きます
  2. 残った表示中のウィンドウのうち、最後に開いたもの(通常は、会議・通話のウィンドウ)を選びます。本アプリの起動前から開いていたウィンドウは開いた時刻が分からないので、その中では大きいものを選びます
  3. 表示中のウィンドウが小窓だけのときは、直前に基準にしたウィンドウの位置を使います
- 追加したアプリは、前面に浮かぶ形式のウィンドウ(Zoomの設定画面など)も対象です。小窓でない大きさのものが表示されていれば、開いた順より優先して基準にします。設定画面でオーディオのテストをすると、その位置から鳴ります
- そのため、会議中に大きいウィンドウ(設定画面など)を新しく開くと、閉じるまではそちらが基準になる場合があります
- システム音(ビープ、通知音)、ブラウザの音、追加したアプリの音は、それぞれ別々に、自分のウィンドウ位置で左右へ振れます。お互いのパンには影響しません
- デスクトップ(Space)を切り替えている間は、ウィンドウがスライドして動くので、パンを動かさず、切り替えが終わってから合わせ直します
- 通話や会議のときは、必要に応じて、オフにしてください

## パンの強さを変える

メニューバーのアイコンにある「パンの倍率」のスライダーで調整します(0.1〜10、設定は保存されます)。左が弱、右が強です。左端から1/3の目盛りが1.0で、その左が0.1〜1、右が1〜10です。マウスのボタンを離すと、システム通知音が1回鳴ります。

- `1.0`: 画面上の位置のとおりに振れます
- `2.0`(初期値): 画面中央から1/4ずれると、反対側が無音になります
- 大きくするほど、極端に振れます

## システム音の初期位置

メニューバーのアイコンにある「システム音の初期位置」のスライダーで、システム音(ビープ、通知音)の基準を、左右にずらせます。設定は保存されます。

- スライダーを動かしてマウスのボタンを離すと、システム通知音が1回鳴るので、聞こえる位置をその場で確かめられます
- 中央(初期値): ウィンドウの位置のとおりに鳴ります
- 右へ動かす: ウィンドウの位置から求めた左右の値に、その分を足します。たとえば、他のMacの右側に置いたMacで、通知音を右から聞きたい場合に使います
- 右端(右 100)まで動かすと、ウィンドウが画面のどこにあっても、中央より左からは鳴りません。画面の左端で中央、画面の中央より右で右端になります。左へ動かした場合は、左右が逆になります
- この設定は、システム音だけに効きます。ブラウザの音と、追加したアプリの音には効きません

## 削除するには

1. メニューバーのアイコンから終了します
2. 「ログイン項目」から外し、`/Applications/SystemSoundPan.app` を削除します
3. 「システム設定 → プライバシーとセキュリティ → マイクとオーディオ録音」の一覧にも残っている場合は、そこからも削除します
