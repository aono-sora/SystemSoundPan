# SystemSoundPan

macOSのシステム音(ビープ・アラート音)を、最前面ウィンドウの画面上の位置に応じて左右にパンするメニューバー常駐アプリです。
昔のMacintoshのように、ウィンドウが画面の左にあれば左から、右にあれば右から音が聞こえます。
ブラウザの動画など、他のアプリの音には影響しません。

作った人: あおのそら(@aono_sora)

本アプリは、Claude Code(Anthropic社のAIコーディングツール)を使って作成しました。

## 作者からの一言

Classic Mac OS(System 7〜Mac OS 9)では、ステレオ対応機でシステムアラート音が画面上のイベント位置に応じて左右にパンニングされる挙動があった。初めてMacintoshに触れた時、この仕組みに感動した覚えがある。ところが現行のmacOSでは、少なくとも私の環境ではこの仕組みを確認できなくなっている。ディスプレイのワイド化や複数ディスプレイ環境が当たり前になった現代だからこそ、この仕組みはあらためて価値を見出せるのではないだろうか。

という純粋な動機から、Claude Codeを使って再現アプリを作ってみました。動作確認など不十分ですが、誰かに刺さってくれれば幸いだと思い公開いたします。

## 本アプリがすること

- システム音を鳴らすプロセス(`systemsoundserverd`)の音だけを取得し、元の音をミュートして、左右バランスを付けて再生し直します
- そのため、macOSの「オーディオ録音」の許可が必要です
- 取得した音声を保存したり、ネットワークに送ったりはしません(通信処理は含まれていません)
- ウィンドウの位置は、最前面アプリのウィンドウの座標だけを読みます。画面の内容やウィンドウのタイトルは読みません
- 通知音(iMessageの着信音など)は、鳴らしたアプリのウィンドウ位置を基準にするため、macOS標準のコマンド `/usr/bin/log stream` を子プロセスとして起動し、「通知音を再生した」「システム音の再生が要求された」というログ行(要求したアプリのバンドルIDやプロセス番号)だけを読みます。それ以外のログの内容は使いません。ログの読み取りに追加の許可は不要です

## 動作条件

- **macOS 14.2 以降**
- **Apple Silicon (M1以降) のみ。** Intel Mac には対応していません

## 動かすための手続き

1. `SystemSoundPan.app` を `/Applications` フォルダにコピーします
2. appをダブルクリックして起動します。「開けません」「開発元を確認できません」と出て止まるのは正常です。いったんそのダイアログを閉じます
3. 「システム設定 → プライバシーとセキュリティ」を開き、下の方に出ている「"SystemSoundPan"は開くのをブロックされました」の横の「このまま開く」を押します。パスワード(またはTouch ID)で認証します

   ターミナルを使える場合は、次の1行でも同じです。
   ```
   xattr -cr /Applications/SystemSoundPan.app
   ```
4. 起動すると、メニューバーに「◐」が出ます(Dockには出ません)
5. 「オーディオを録音しようとしています」という許可ダイアログが出たら、許可します
6. **初回の起動時だけ、動き出すまでに十数秒かかることがあります**(許可の確認のため)。許可後は、起動してすぐ動きます。動き出す前のシステム音は、通常どおり(パンなしで)鳴ります
7. ターミナルで `osascript -e 'beep 2'` を実行し、ウィンドウを画面の左右に動かして音の左右が変わるか確認します

## 自動起動

「システム設定 → 一般 → ログイン項目と拡張機能」で「+」を押し、`/Applications/SystemSoundPan.app` を追加します。
外付けドライブ上のappは、未接続だと起動に失敗するので、`/Applications` に置いてください。

## 使い方

- メニューバーの「◐」から、オン/オフの切り替え、「パンの倍率…」の入力、「ブラウザの音もパンする」の切り替え、終了ができます(オフにすると「○」になり、システム音は元の鳴り方に戻ります)
- 基準にするのは、ウィンドウの中心のX座標です。複数ディスプレイの場合は、全ディスプレイを並べた全体の幅が基準です
- ビープ音などは、最前面アプリのウィンドウが基準です
- 通知音は、通知を出したアプリのウィンドウが画面に表示されていれば、そのウィンドウが基準です(iMessageの着信音で確認済み)。表示されていなければ、最前面アプリのウィンドウが基準です
- 通知を出したアプリのウィンドウが複数ある場合は、最前面にあるウィンドウを使います
- ブラウザ上のWebアプリ(Web版のOutlookなど)が自分で鳴らす通知音は、システム音ではなくブラウザの音なので、初期状態では対象外です(ブラウザの動画などの音を通常どおり出すため)。メニューの「ブラウザの音もパンする」をオンにすると、対象になります。ただし、ブラウザの音は動画も含めて全部が対象になり、動画の音も左右に振れます(映像と音が少しずれる可能性もあります)。動画を見るときはオフに戻すことを推奨します。対応ブラウザは、Chrome、Edge、Brave、Firefox、Safariです。この場合の基準は、ブラウザのウィンドウ位置です。特定のサイトの音だけを振りたい場合もあるので、Chrome拡張機能「Desktop Audio Panner」(許可リスト式)を開発中です。

## パンの強さを変える

メニューバーの「◐」→「パンの倍率…」で、数値を入力します(0.1〜10、再ビルドは不要です。設定は保存されます)。

- `1.0`: 画面上の位置のとおりに振れます
- `2.0`(初期値): 画面中央から1/4ずれると、反対側が無音になります
- 大きくするほど、極端に振れます

## 削除するには

1. メニューバーの「◐」から終了します
2. 「ログイン項目」から外し、`/Applications/SystemSoundPan.app` を削除します
3. 「システム設定 → プライバシーとセキュリティ → マイクとオーディオ録音」の一覧にも残っている場合は、そこからも削除します
